# DeskOrb Agent 安装注意说明

版本：0.2.0（Windows x64）

## 一、安装包说明

DeskOrb Agent 安装包已经包含程序运行所需的主要组件：

- DeskOrb Agent 主程序；
- 独立的 Python 运行时和项目依赖；
- Node.js；
- PowerShell 7；
- MinGit；
- Playwright MCP 及 Chromium；
- OfficeCLI。

通常只需要运行 `DeskOrb-Agent-0.2.0-Setup-x64.exe`，不需要另外安装 Python、Node.js、Git 或 Playwright。

当前安装包大小约为 421 MB。安装过程中会解压完整运行环境，建议目标磁盘至少预留 2 GB 可用空间。

## 二、安装目录可以自定义

安装向导默认使用：

```text
D:\DeskOrb Agent
```

安装向导会显示“选择安装目录”页面。点击“浏览”即可选择其他目录或盘符，例如：

```text
D:\Apps\DeskOrb Agent
E:\DeskOrb Agent
C:\Users\用户名\Apps\DeskOrb Agent
```

安装器按当前用户权限运行，不要求管理员权限。请选择当前账户有写入权限的目录，推荐使用 D 盘、E 盘或用户目录。非管理员账户不要选择以下系统目录：

```text
C:\Program Files
C:\Program Files (x86)
C:\Windows
```

建议选择一个新的本地 NTFS 文件夹，不要直接安装到项目源码目录、网络盘、U 盘或正在同步的云盘目录。

## 三、推荐安装步骤

1. 关闭正在运行的旧版 DeskOrb Agent。
2. 双击运行 `DeskOrb-Agent-0.2.0-Setup-x64.exe`。
3. 阅读许可协议。
4. 在“选择安装目录”页面点击“浏览”，确认或修改安装路径。
5. 点击“安装”，等待运行环境解压完成。
6. 安装完成后，可以运行安装目录中的 `DeskOrb Agent.lnk`，或运行 `Start DeskOrb Agent Portable.cmd`。

请使用普通双击方式启动安装包。如果通过命令行使用 `/SILENT` 或 `/VERYSILENT` 参数，安装向导页面会被隐藏，无法看到目录选择页面。

## 四、首次启动前的配置

AI 功能需要配置用户自己的 API Key。安装包不包含任何 API Key，也不会自动写入密钥。

请在 DeskOrb Agent 的 Connection settings 中配置 Provider、Model ID、API base URL 和 API Key，或者根据项目提供的 `.env.example` 创建本地配置文件。真实的 `.env` 文件不要上传、提交 Git 或放入安装包。

Provider 必须和 API 地址、模型以及密钥属于同一服务：

- OpenAI Responses API：选择 `openai` 或 `responses`；
- OpenAI-compatible Chat Completions 服务：选择 `openai-compatible`；
- DeepSeek：选择 `deepseek`；
- 通义千问 / DashScope：选择 `qwen`。

保存设置后，聊天记录会显示实际使用的 Provider。密钥会按 Provider 分开保存到 Windows Credential Manager，避免把一个服务的密钥误用于另一个服务。

首次运行时如果 Windows Defender 或其他安全软件需要扫描较大的运行时目录，请等待扫描完成。若出现 SmartScreen 未识别发布者提示，请先核对安装包来源和 SHA-256，再决定是否继续运行。

## 五、可选外部依赖

### Microsoft Office

OfficeCLI 本身已经包含在安装包中，普通文件处理不要求安装 Office。但如果需要读写当前打开且包含未保存修改的 Word 或 Excel 文档，计算机上需要安装 Microsoft Office 桌面版。

### PowerToys

PowerToys 不是安装包内置组件。未安装 PowerToys 时，DeskOrb Agent 主程序仍可以运行，但 PowerToys MCP 相关功能不可用。

### WhisperX

主安装包不包含 WhisperX 虚拟环境和语音模型。只有使用会议录音、语音转写等功能时，才需要按项目说明额外运行 `setup-whisperx.cmd`。WhisperX 及语音模型会占用较多磁盘空间，并可能在首次使用时下载模型。

## 六、安装失败或启动异常排查

### 看不到“选择安装目录”页面

- 确认运行的是最新的 `DeskOrb-Agent-0.2.0-Setup-x64.exe`；
- 不要使用 `/SILENT` 或 `/VERYSILENT` 参数；
- 如果安装包来自其他电脑或下载位置，请重新复制最新安装包，避免使用旧的同名文件。

### 输入有效 API Key 后仍然返回 HTTP 401

“有效”必须是相对于当前 Provider 和 API base URL 有效。请在 Connection settings 中同时核对：

1. Provider 是否与服务协议一致；
2. API base URL 是否属于该服务；
3. Model ID 是否是该服务实际提供的模型；
4. API Key 是否属于该服务，并且没有把 `Bearer ` 前缀重复粘贴进去。

如果使用 OpenAI-compatible 服务，请选择 `openai-compatible`，不要继续使用 `auto` 推断协议。新版程序会在错误信息中显示实际 Provider 和 endpoint，便于定位配置不匹配。

### 提示无法写入目录

请改选当前用户有权限写入的目录，例如：

```text
D:\DeskOrb Agent
D:\Apps\DeskOrb Agent
C:\Users\用户名\Apps\DeskOrb Agent
```

不要直接选择 `C:\Program Files` 等需要管理员权限的系统目录。

### Office 功能不可用

确认本机安装了 Microsoft Office 桌面版，并使用与当前用户相同的账户启动 DeskOrb Agent。OfficeCLI 的文件操作功能不等于已经安装了 Office。

### 安装包被安全软件拦截

先确认安装包来自可信来源，并核对 SHA-256。不要关闭系统安全软件来运行来源不明的安装包；如果确认是误报，再按本机安全策略将安装包或安装目录加入允许列表。

## 七、卸载

可以从 Windows“设置 → 应用 → 已安装的应用”中卸载 DeskOrb Agent，也可以运行安装目录中的卸载程序。卸载前请先退出 DeskOrb Agent，并备份需要保留的个人配置、日志或录音文件。

卸载后如需重新安装，建议选择一个新的空目录，避免旧版本残留文件影响排查。
